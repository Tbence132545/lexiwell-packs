# Lexiwell language packs

Dictionary packs downloaded by the [Lexiwell](https://github.com/Tbence132545) reading app.
They are published as release assets (`*.sqlite.gz`, gzip-compressed SQLite files) together
with a `manifest.json` listing each pack's languages, sizes and SHA-256 checksum.
